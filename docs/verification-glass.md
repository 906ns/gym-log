# Liquid Glass UI 検証

## 実装

- `css/glass.css` / `js/views/liquid-glass.js`: liquid-glass-ui スキルの配布素材を無変更で配置。
- `index.html`: ヘッダーと下部ナビゲーションの2面に適用。下部ナビは余白を持つフローティング配置。
- `css/style.css`: 炭・スチール・真鍮の変数、スクロール領域と固定ナビの余白を調整。
- `js/views/glass.js`: 初期化と透明度設定を既存の設定用repo APIで保存。
- `js/views/settings.js`: 「透明度オフ」を追加。バックアップ復元時も表示設定を同期。
- `js/views/shell.js`: 選択タブに内側の面を適用。
- `js/app.js`: 起動時にガラスを初期化。
- `sw.js`: 新規静的ファイルをキャッシュ対象に追加し、キャッシュ名を更新。

## 判断した箇所・仕様との差分

- 記録カード、入力欄、セッション画面には適用せず、常設ナビゲーションに限定した。
- 透明度設定は既存IndexedDB metaへ保存。localStorageは追加していない。データモデル・集計・種目ID・記録処理は変更していない。
- ユーザー指定のスキルを優先し、配布素材用CSSを別ファイルとして追加。従来の影なし方針に対し、配布素材の内側ハイライトは使用し、外側の影は変数で無効にした。
