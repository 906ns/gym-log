# UI 仕様

## 0. 設計の方向

ジムのマシンから引いている。フレームは炭色、支柱はブラッシュドスチール、
重量を選ぶピンだけが真鍮色をしている。**画面上で色が付くのは、その真鍮の1色だけ**。
他はすべて炭とスチールの無彩色で、数値だけが読める状態にする。

ダーク基調にする理由は3つ。夜のジムで眩しくないこと、有機ELで電池を食わないこと、
自宅で体重を入れるのが朝夕であること。

**このアプリの主役は重量の数字**。装飾を足すのではなく、数字を大きくして周りを黙らせる。

避けること:

- ラベルの全角大文字・英大文字化（`WEIGHT` のような表記）
- ボタン文字への矢印の付加（`記録する →`）
- 見出しの上に置く小さな英字ラベル
- 全要素を同じ角丸・同じ影の四角に切る作り
- 中黒で連結したメタ情報（`胸 · マシン · 45kg`）
- ホバー時のアニメーションや、セクションごとのフェードイン

## 1. トークン

`css/style.css` の `:root` に定義する。この値以外の色をコード中に直接書かない。

### 色

```css
:root {
  --bg:        #16191B;  /* 炭。マシンのフレーム */
  --surface:   #1F2427;  /* カード面 */
  --surface-2: #272D31;  /* 入力欄・押し込み面 */
  --line:      #333A3F;  /* 罫線 */
  --text:      #E9ECEC;  /* 本文 */
  --muted:     #98A1A6;  /* 補助情報、前回記録の文字 */
  --brass:     #C9992F;  /* 真鍮。アクセントは全画面でこの1色のみ */
  --steel:     #7E949E;  /* 数値の補助、休憩の目標到達後 */
  --danger:    #B4544A;  /* 破壊的操作のみ */
}
```

`--brass` を使える場所を限定する。主ボタン、休憩の経過時間（目標未達の間）、
選択中のタブ、メモがある行の印。それ以外に使わない。
「どこでも使える色」にした瞬間にアクセントとして機能しなくなる。

### 文字

書体はシステムフォントのみ（オフライン前提、Web フォント禁止）。

```css
--font: -apple-system, BlinkMacSystemFont, 'Hiragino Sans', 'Noto Sans JP', sans-serif;
```

数値には `font-variant-numeric: tabular-nums` を必ず指定する。
セットが縦に並んだとき桁が揃わないと読めない。装飾ではなく可読性の要件。

型階層:

| 用途 | サイズ / 行間 / 太さ | 備考 |
| --- | --- | --- |
| 重量の主数値 | 44px / 1.0 / 600 | 種目カードの入力欄。`tabular-nums` |
| 体重の主数値 | 34px / 1.1 / 600 | ホームの体重カード |
| 画面見出し | 22px / 1.3 / 600 | |
| 種目名 | 18px / 1.35 / 600 | |
| 本文・セット行 | 17px / 1.5 / 400 | セット行の数値は 500 |
| 補助・前回記録 | 15px / 1.5 / 400 | `--muted` |
| 注記 | 13px / 1.45 / 400 | `--muted`。確認文や単位 |

**入力欄の `font-size` は最低 16px**。下回ると iOS Safari がフォーカス時に
自動ズームして、入力のたびに画面が動く。

### 間隔と形

```css
--sp-1: 4px;  --sp-2: 8px;  --sp-3: 12px;
--sp-4: 16px; --sp-5: 24px; --sp-6: 32px;

--r-card: 10px;   /* カード */
--r-ctl: 8px;     /* ボタン・入力欄 */
--r-pill: 999px;  /* 部位フィルタのみ */
```

角丸を3種に絞り、要素の役割で使い分ける。全部同じ半径にすると階層が消える。
影は使わない。面の区別は `--surface` の明度差と `--line` の罫線で付ける。

### タップ領域

| 要素 | 最小サイズ |
| --- | --- |
| 主ボタン（記録する、開始する） | 高さ 56px |
| `+` / `−` ボタン | 52 × 52px |
| セット行、前回記録の行 | 高さ 48px |
| アイコンボタン（メモ、編集） | 44 × 44px |

汗ばんだ手の片手操作を前提にする。44px を下回る操作要素を作らない。
`+` / `−` は連打するので、画面の左右端ではなく親指の届く中央寄りに置く。

## 2. 画面: ホーム

```
┌───────────────────────────────┐
│                               │  ← safe-area
│  体重                          │
│  68.4 kg          −0.4        │  ← 主数値 34px / 差分は --steel
│  9月14日（日）に測定             │
│                               │  ← カード全体がタップ領域
├───────────────────────────────┤
│                               │
│   ┌─────────────────────────┐ │
│   │  今日のトレーニングを開始   │ │  ← 高さ56px / 背景 --brass / 文字 #16191B
│   └─────────────────────────┘ │
│                               │
│  最近                          │
│  ───────────────────────────  │
│  9月12日（金）                  │
│  4種目 / 4,280 kg              │
│  肩に張りあり                    │
│  ───────────────────────────  │
│  9月10日（水）                  │
│  3種目 / 3,150 kg              │
│  ───────────────────────────  │
│  （最大5件）                    │
│                               │
│                    ⚙          │  ← 設定へ。右下固定
└───────────────────────────────┘
```

- 体重カードは最上部。自宅で朝に開く用途がここに集まる。
- 履歴はカードに切らず、罫線で区切ったリストにする。同じ形のカードを
  縦に積むと、どれも同じ重みに見えて日付を追えない。
- 差分は符号付きで出す。増減に色を付けない（増えたら赤、のような表現は
  目的によって意味が反転するため、判断を押しつけない）。
- 進行中セッションがある場合、この画面は表示せず直接セッション画面へ遷移する。
  ただし戻れるように、セッション画面のヘッダーにホームへの導線を置く。

### 体重入力（モーダル）

```
┌───────────────────────────────┐
│  体重を記録                     │
│                               │
│  9月15日（月）        ［変更］    │
│                               │
│   −     [  68.4  ] kg     +   │  ← 増減は 0.1
│                               │
│   体脂肪率（任意）               │
│   −     [  18.2  ] %      +   │  ← 増減は 0.1 / show_body_fat=false なら非表示
│                               │
│   ┌─────────────────────────┐ │
│   │        記録する          │ │
│   └─────────────────────────┘ │
│           やめる                │
└───────────────────────────────┘
```

前回値をプリフィルするので、多くの場合 `+` / `−` を数回押して記録するだけで終わる。

### 日付の選択（2026-09）

日付はネイティブのピッカーを使わず、シート内の日付ボタンから候補一覧を開く。
候補は年・月・日・曜日を表示する高さ56px以上の行とし、タップすると一覧を閉じて選択値を日付ボタンに表示する。
14日ごとの「前の14日」「新しい14日」で移動でき、古い記録もキーボードなしで選べる。

- 「過去の日付で記録する」は日付未選択で開く。昨日からの14日を候補にし、今日・未来は出さない。選択後に「記録を始める」を押す。未選択での開始は既存の保存時検証で拒否する。
- 体重の測定日は今日を初期値にする。変更時は今日を含む14日を表示し、過去の日付も選べる。同じ測定日の保存は既存レコードを上書きする。
- シート内のエラーは取っ手・見出しの下、操作内容の上に表示する。

## 3. 画面: セッション

```
┌───────────────────────────────┐
│ ←  9月15日（月）      1:12:40  │  ← 開始からの経過 / --muted
│                       ［終了］  │
│ ───────────────────────────── │
│ 肩に張りあり              ✎     │  ← コンディションメモ。空なら「体調をメモ」
│ ───────────────────────────── │
│                               │
│ ┌───────────────────────────┐ │
│ │ チェストプレス     3セット   │ │  ← 閉じた種目カード
│ │                  最大45kg  │ │
│ └───────────────────────────┘ │
│                               │
│ ┌───────────────────────────┐ │
│ │ ラットプルダウン            │ │  ← 開いた種目カード（後述）
│ │  ...                      │ │
│ └───────────────────────────┘ │
│                               │
│   ＋ 種目を追加                 │
│                               │
│                               │
│ ───────────────────────────── │
│  休憩  1:23                   │  ← 固定フッター / --brass
└───────────────────────────────┘
```

- 開くのは常に1種目だけ。別の種目を開くと前の種目は閉じる。
  ジムでは1種目ずつ進むので、複数開けても画面が長くなるだけ。
- 種目カードは記録した順に並ぶ。並べ替えはしない。
- 固定フッターは `env(safe-area-inset-bottom)` を足した高さにする。

### 開いた種目カード

```
┌───────────────────────────────┐
│ ラットプルダウン                 │
│                               │
│ 前回 9/12                      │  ← --muted 15px
│  45.0 kg  × 10           ⤓    │  ← ⤓ = この値を入力欄に入れる
│  45.0 kg  ×  9   最後きつい ⤓  │  ← セットメモを併記
│  40.0 kg  × 10           ⤓    │
│                               │
│ 今日                           │
│  45.0 kg  × 10           ✎    │  ← ✎ でメモ / 行タップで編集
│                               │
│ ┌───────────────────────────┐ │
│ │  −      45.0  kg       +  │ │  ← 主数値 44px / 増減 weight_increment
│ │  −        10  回       +  │ │  ← 増減 1
│ │  ┌─────────────────────┐  │ │
│ │  │      記録する        │  │ │  ← 高さ56px / --brass
│ │  └─────────────────────┘  │ │
│ └───────────────────────────┘ │
│                               │
│ シート4、背もたれ2         ✎    │  ← setup_note。空なら非表示
└───────────────────────────────┘
```

- **「前回」が「今日」より上**。開いた瞬間に目に入るべきものが前回の記録だから。
- 数値は右揃えの `tabular-nums`。`kg` と `回` は `--muted` の 13px。
- 入力欄は `--surface-2` の面に載せ、カード内で一段沈ませる。
- `⤓` は 44×44px のタップ領域を確保する。アイコンだけで意味が伝わらないので、
  初回のみ「前回の値を入れる」という小さな注記を1行出してよい。
- セットを記録したら、その行が「今日」の末尾に増える。ここだけ 120ms の
  高さアニメーションを入れる（何が起きたかを示す動き）。他の場所に動きは入れない。

### 種目ピッカー（下から出るシート）

```
┌───────────────────────────────┐
│ 種目を選ぶ               閉じる │
│                               │
│ (すべて) (胸) (背中) (肩) (脚)  │  ← pill。選択中のみ --brass の枠線
│                               │
│  チェストプレス          記録済  │
│  ラットプルダウン               │
│  レッグプレス                   │
│  ペックフライ                   │
│  ...                          │
│                               │
│  ＋ 種目を新規作成              │
└───────────────────────────────┘
```

並びは直近に使った順（五十音順にしない）。「記録済」は印だけで、選択は可能。

## 4. 画面: 設定

罫線区切りのリスト。カードに切らない。

```
種目
  チェストプレス            胸    ›
  ペックフライ              胸    ›
  ...
  ＋ 種目を追加

トレーニング
  目標休憩秒数                90秒 ›
  体脂肪率を入力する             [on]

データ
  バックアップを書き出す            ›
  バックアップから復元する          ›
  データの保持              許可済み
  セッション 12 / セット 218 / 体重 30

このアプリ
  バージョン                 1.0.0
  キャッシュ              gym-log-v1
```

- 「復元する」は `--danger` の文字色にし、確認ダイアログで
  「現在の記録がすべて置き換わります」と明示する。
- 「データの保持」は `navigator.storage.persisted()` の結果。
  「未許可」の場合は、ホーム画面に追加して使うことと、定期的に
  バックアップを書き出すことを1行で案内する。

### 種目の編集

名前、英語表記、部位、重量刻み、目標休憩秒数、セッティングメモ、
アーカイブのトグル。削除は置かない（記録が参照しているため、アーカイブで隠す）。

## 5. 状態とアクセシビリティ

| 状態 | 表現 |
| --- | --- |
| フォーカス | `outline: 2px solid var(--brass); outline-offset: 2px`。消さない |
| 押下 | `transform: translateY(1px)` と `--surface-2` への背景変化 |
| 無効 | `opacity: .4` と `pointer-events: none`。色は変えない |
| 読み込み中 | v1 では出さない（すべてローカルで即時完了する） |

- `prefers-reduced-motion: reduce` でセット追加のアニメーションを無効にする。
- 色だけで情報を伝えない。休憩の目標到達は色の変化に加えて表示を
  `1:35 / 90秒` の形にする。
- アイコンのみのボタンには `aria-label` を付ける。
- 本文とボタンの文字は `--text` / `#16191B` で、コントラスト比 4.5:1 以上を確保する。
  `--muted` は 15px 以上の文字にのみ使う。

## 6. 文言の方針

- 動詞で書く。「記録する」「書き出す」「やめる」。「送信」「OK」は使わない。
- ボタンの語をその後の表示でも揃える。「記録する」を押したら「記録しました」。
- エラーは謝らない。何が起きたかと、次に何をすればいいかだけを書く。
- 空の状態は説明ではなく誘導にする。「まだ記録がありません」の下に開始ボタンを置く。
- 単位は数値の直後に小さく置く。ラベルとして上に出さない。

## 7. HTML の構造

`index.html` 1枚に3画面分のマークアップを入れ、`hidden` 属性で切り替える。
`<template>` を使って繰り返し要素（セット行、種目カード、履歴行）を定義し、
`cloneNode(true)` で複製する。`innerHTML` による生成は禁止（`AGENTS.md` 参照）。

```html
<main>
  <section id="view-home">...</section>
  <section id="view-session" hidden>...</section>
  <section id="view-settings" hidden>...</section>
</main>
<template id="tpl-set-row">...</template>
<template id="tpl-prev-set-row">...</template>
<template id="tpl-exercise-card">...</template>
<template id="tpl-history-row">...</template>
<dialog id="dlg-body-weight">...</dialog>
<dialog id="dlg-exercise-picker">...</dialog>
<dialog id="dlg-confirm">...</dialog>
```

`<dialog>` の `showModal()` は iOS Safari 15.4 以降で使える。自前のオーバーレイを
組まずにこれを使う。フォーカストラップと背景スクロールの抑止が標準で効く。

## セッション画面の小画面対応（2026-09、1-1再追撃）

390×568で前回3セットと入力欄を同時に表示するため、セッション画面は次のフレックス列で構成する。この節は上記のカード内入力・固定休憩表示の配置に優先する。

1. ヘッダー
2. スクロール領域（種目カード、体調メモ、種目追加）
3. 選択中の種目の入力パネル（選択がなければ非表示）
4. 休憩フッター（記録前・過去記録では非表示）

入力パネルと休憩フッターはスクロール領域の外で固有の高さを確保し、セット行に重ねない。重量とレップは横並び、文字サイズ22px、増減ボタンは44px以上。記録ボタンは高さ56px。「刻み」ボタンから増減幅の選択シートを開く。設定の保存先・永続化の挙動は従来と同じ。

カードは種目名・開閉操作・前回の全セット・今日のセット・自己ベストと推定1RMの順。前回行のタップで値を入力パネルへ転記する。種目を開いた際はカード先頭を表示し、記録後は一覧のスクロール位置を維持する。体調メモは種目カードの後へ配置する。
