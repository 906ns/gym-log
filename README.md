# gym-log

iPhoneで、前回のセットを見ながら重量とレップを記録する個人用PWAです。データは端末のIndexedDBに保存します。外部通信、認証、実行時依存、ビルドはありません。

## 起動

リポジトリ内で、公開用ファイルだけを確認用フォルダへコピーして実行します。

```sh
mkdir -p /tmp/gym-log-preview/gym-log
cp -R index.html css js icons data manifest.webmanifest sw.js /tmp/gym-log-preview/gym-log/
python3 -m http.server 8000 --bind 127.0.0.1 --directory /tmp/gym-log-preview
```

ブラウザで `http://localhost:8000/gym-log/` を開きます。HTTPSまたはlocalhostが必要です。GitHub Pagesでは `https://906ns.github.io/gym-log/` にリポジトリ直下を配信します。

## iPhoneへの追加

1. Safariで公開URLを開く。
2. 共有メニューから「ホーム画面に追加」を選ぶ。
3. ホーム画面のGLアイコンから起動する。
4. 初回の読み込みを終えてからオフラインで使用する。

種目を追加してカードを開くと前回の全セットが上に出ます。前回の行をタップして「記録する」を押します。種目の重量刻みは仮の5 kgです。実際のマシンに合わせて設定で変更してください。進行中の記録は次の起動時に自動で開きます。

## バックアップ

設定の「バックアップを書き出す」でJSONを保存してください。復元は現在の全記録を置き換えます。検証と確認後に一括で適用します。ブラウザのサイトデータを消すと端末内の記録も失われるため、定期的なバックアップを推奨します。

## 開発と更新

```sh
npm test
```

Node.js標準のテストランナーだけを使います。インストールやビルドは不要です。JSはESM、画面はDOM APIで構築しています。

App Shellのファイルを変更したら、`sw.js` のキャッシュ名を必ず上げ、設定画面の表示も合わせます。ファイルを増やした場合は `SHELL` にも追加します。新しいService Workerは既存の画面を閉じた後に有効になるため、更新後はすべてのタブとホーム画面アプリを閉じて開き直してください。

IndexedDBの構造を変える場合は `SCHEMA_VERSION` を上げ、既存処理を書き換えず移行ブロックを追記します。DB構造はバージョン3（既存のバージョン2に種目の単位設定移行を追記）、JSON転送形式はバージョン2です。バージョン1のバックアップも読み込めます。metaはkeyを主キーとしてUUIDと共通日時も保持します。シード種目はJSONの固定UUIDを使います。

## 実機での確認

- ホーム画面からアドレスバーなしで起動できること。
- 重量・レップの入力時にSafariがズームしないこと。
- 下端の休憩表示がホームインジケータに重ならないこと。
- セッション画面のWake Lockとバックグラウンド復帰時の休憩表示。
- 機内モードで全画面を開き、記録を追加し、再起動後も残ること。
- 日付を翌日に変えて前回の値・メモが表示されること。
- JSONの保存・復元と、データ保持許可の表示。

## v1.1

設定でkg / lbを切り替えられます。種目ごとの指定は全体設定より優先されます。保存と集計は常にkgです。入力中の刻みは1 / 2.5 / 5 / 10から選び、増減ボタンは長押しできます。種目名を押すと履歴・自己ベスト・セッティングメモを開きます。セット行から重量・回数・メモの編集と削除、休憩表示から目標の±15秒調整ができます。

ホームのカレンダーから履歴を確認できます。過去日付の記録では休憩時間を表示せず、終了サマリーの所要時間は「未記録」にします。週次ヘッダーと小さな推移線は既存記録から導出します。

調査と採用範囲は [docs/research.md](docs/research.md)、検証結果・判断した箇所は [docs/verification-v1.1.md](docs/verification-v1.1.md) を参照してください。

## v1.2の画面とテーマ

ホーム・履歴・設定は下端のタブで移動します。記録画面の下向きアイコンは画面を閉じるだけで、トレーニングは終了しません。タブ上のミニバーから戻れます。終了するときは記録画面の「終了」を使います。

設定の「表示」でダーク・ライト・システムに従うを選べます。設定は既存のIndexedDBのmetaに保存し、テーマだけを描画前のキャッシュとしてlocalStorageの `gym-log-theme` にも保持します。他の設定・記録にはlocalStorageを使いません。テーマキャッシュの読み書きはhead内の同期スクリプトだけです。

v1.2のUI更新ではDBバージョン・保存形式・計算を変更していません。確認結果と判断は [docs/verification-v1.2.md](docs/verification-v1.2.md) を参照してください。
